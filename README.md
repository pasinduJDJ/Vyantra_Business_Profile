# Vyantra Global Engineering business profile

## Local preview

Open `index.html` in a browser, or run `python -m http.server 8000` from this folder and open `http://localhost:8000`.

## Project files

- `index.html` contains the banner and four sections in navigation order.
- `assets/css/style.css` controls the responsive layout and fixed navy, white and gold palette.
- `assets/js/main.js` handles mobile navigation, the services carousel and vCard download.
- `assets/images/hatchery-banner.webp` is the approved illustrative banner. The equipment imagery is also illustrative and may differ from exact product models.

The services carousel auto-advances while visible and loops continuously and pauses on hover or focus and supports native touch scrolling. It starts paused when the browser requests reduced motion.

## Spaceship hosting

Upload the updated `index.html` and `assets` files to the existing document root for `profile.vyantraglobal.com`. Keep the folder structure intact.
